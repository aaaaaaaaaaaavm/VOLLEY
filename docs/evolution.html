How the concept changed

The mission objective survived several unbuilt mechanism studies. No current next-generation mechanism is selected.

Open workStatus record

Original objective

A host-mounted reusable launcher with a controlled loading path would release ordinary CubeSats one after another at individually commanded speeds.

Electromagnetic model

Gen5 studied an electromagnetic linear motor and magazine. Its numerical values are configuration-specific model outputs and are not physical demonstrations.

Withdrawn architecture choices

A long gas guide and a bank of separate motor-charged spring cells were later investigated. Neither established the requested reusable shared path or the broad release-speed authority.

Reopened trade

The shared feeder, retention path, drive, catcher, installed burden and host interface must now be compared before another architecture is selected.
