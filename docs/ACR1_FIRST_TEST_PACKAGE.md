# First measurements after ACR1

**25 October 2026 — subsequent Gen6 preparation.** The completed ACR1 computational reference supplies defined geometry, source/current predictions, custody logic and release/arrest studies. The [N5-R1 first-test packet](../validation/acr1_first_test_package/README.md) converts selected uncertainties into limited, unfunded bench procedures. No physical measurement or build authorization is claimed.

The [BOM](../validation/acr1_first_test_package/BOM.csv) distinguishes controlled dimensions and catalog references from unselected materials, instruments and fixtures. The [uncertainty/calibration procedure](../validation/acr1_first_test_package/TEST_PROCEDURE.md) freezes comparison bands before validation data. Empty templates remain visibly unperformed.

Three limits matter. The legacy four-block bench wavelength differs from ACR1's six-block, 60° sequence. ACR1's active LSM arrest is not the historical eddy brake. Ground gravity/support changes contact and egress: ordinary sliding cannot represent the proposed low-drag release rig. The source elastic-energy bound also requires submicrometre compliance metrology before it can be physically correlated.

The [release-dynamics physical specification](../validation/acr1_release_dynamics/PHYSICAL_TEST_SPECIFICATION.md) retains the broader source/contact/pose and repeatability requirements. The packet does not establish a measured 3 m/s setting, mixed 1U/3U compatibility, hot/vacuum behavior, endurance or provider qualification. Current Gen5/ED1 artifacts remain unchanged.
