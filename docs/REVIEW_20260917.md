## Executed result

authority screens, two navigation/control policies, zero or 120 s post-release
coast, shared-error corners at three scales and independent release-only corners.
Actual first-event retained-host errors propagate through the second transfer
and release. The implementation never resets that host to its nominal state.

The base shared box accepts all 64 sampled corners in each screen/policy/delay
combination. Larger boxes retain terminal-state misses and local search failures.
These are deterministic sampled outcomes, not probabilities or continuous-box
guarantees. Exact-state replanning reduces second-payload error but does not
repair a first payload after separation.

In the wider-authority zero-error replay case, the 120 s coast increases host
fuel from 2.777987 to 3.181084 kg. The nominal second transfer is re-solved for
the delay; it is not a fixed command shifted in time. A 120 s schedule interval
does not establish clearance, plume safety or attitude settling.

All twelve declared numerical checks pass, including independent fixed-step
RK4, analytic circular motion, tighter adaptive propagation, zero-error S4
reproduction, momentum/relative velocity, mass and coast invariant checks.
The 10 m and 0.01 m/s physical terminal bands are unchanged. Ten new focused
tests pass; the complete test suite has 150 passing tests in the development
environment. CI and publication status belong to the final commit's Actions
record, not to a claim that tests constitute hardware validation.

The first full local gate exposed two publication failures. The inherited
CadQuery 2.7 runtime did not reproduce the committed CAD; installing the declared
`requirements-cad.txt` runtime (2.8) reproduced both packages byte-identically.
The S7 report also depended on dictionary insertion order, so its verification
rows changed after sorted JSON serialization. Sorting those rows explicitly and
adding a serialization-order regression test fixes the report without changing
any physical limit or numerical acceptance criterion. Both failures are retained
here; neither is treated as a new hardware finding.
