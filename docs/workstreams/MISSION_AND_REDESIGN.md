# Mission and redesign

## Current position

The brochure presents the mission and the current evidence. The next engineering deliverable is a complete multi-payload terminal-state mission comparison. Gen6 is not reselected. Existing 8 m gas-guide evidence remains a comparator.

## Ordered deliverables and exit conditions

1. **Three reference missions.** Propulsion-less individual delivery, initial group distribution and replenishment. Declare full position/velocity targets, timing/tolerances, host resources, uncertainty, useful mission duration and disposal assumptions before running the study.
2. **Complete campaign comparison.** Springs plus release timing, host manoeuvres, programmable deployment and cooperative BOLLEY under identical targets. Include changing host mass/recoil/propellant, release-time search and its convergence, attitude recovery/settling, resource depletion and final host condition. A feasible state or lower propellant total alone is not superiority.
3. **Installed burden and failure architecture.** Compare independent bays, banks and shared magazine. Account for occupied envelope, support structure, containment, power, controls, deployment energy, operations, cost assumptions and successfully delivered payloads. Model a blocked path and shared power/control failures. Separate safe retention from recoverable deployment.
4. **Provider accommodation.** Calculate geometry, forces/torques, recoil, energy, power, cadence and attitude demands. Request a disposition against a named host configuration; keep public information, study assumptions and missing ICD data distinct.
5. **Configuration decision.** Select among controlled stored-energy, electromechanical and gas mechanisms under the same requirements; charge BOLLEY's cooperative interface. Record the ADR and P92/P113 dispositions. Do not adopt 29, 89 or 120 m/s without a mission-derived requirement.
6. **One release cell.** Use decisive early coupons to resolve friction/contact/actuator uncertainty; produce coupled dynamics, structural/tolerance, thermal, controls and fault evidence for the selected cell.
7. **Scaling and build package.** Compare 2/4/12-cell campaigns, adjacent payload sizes and independent banks. Produce drawings, BOM, assembly/inspection, instrumentation/calibration, uncertainty and acceptance criteria for a named test article. External review and physical testing remain required.

## Boundaries

This stream owns README presentation assets, new mission studies, requirement/configuration ADRs and selected release-cell interfaces. The closure stream can analyze the existing gas design and supply reusable results. Do not combine evidence from different geometries, payload interfaces or force duties without a new validation path.
