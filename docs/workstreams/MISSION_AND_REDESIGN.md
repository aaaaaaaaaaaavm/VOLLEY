# Mission and redesign

## Current position

The visual front end now presents S1–S4 as four bounded mission-study layers. P113-S4 is merged with 100 two-payload schedule/order/authority cases, generated evidence and a normal freshness gate. Forty-four tested campaigns are accepted. P113/E5 remain open because this is not a full-manifest or installed-system comparison.

The next engineering deliverable is to turn those mission results into architecture requirements and run P92 without preselecting a mechanism. Existing 8 m gas-guide evidence remains a comparator. No clean-sheet Gen6 mechanism is selected or rendered as the design.

## Ordered deliverables and exit conditions

1. **Architecture-driving mission requirements.** Preserve the propulsion-less individual, initial group distribution and replenishment mission hypotheses, but now add the terms S4 leaves outside the ideal screen: clearing/settling time, release/navigation uncertainty, host attitude recovery, installed deployment burden and complete-manifest effects. Declare the target states, windows, tolerances and host limits before extending the solver.
2. **Complete campaign comparison.** Springs plus release timing, host manoeuvres, programmable deployment and cooperative BOLLEY under identical targets. Carry changing host mass/recoil/propellant, release-time search and convergence, attitude recovery/settling, resource depletion and final host condition. A feasible state or lower propellant total alone is not superiority.
3. **Installed burden and failure architecture.** Compare independent bays, banks and shared magazine. Account for occupied envelope, support structure, containment, power, controls, deployment energy, operations, cost assumptions and successfully delivered payloads. Model a blocked path and shared power/control failures. Separate safe retention from recoverable deployment.
4. **Provider accommodation.** Calculate geometry, forces/torques, recoil, energy, power, cadence and attitude demands. Request a disposition against a named host configuration; keep public information, study assumptions and missing ICD data distinct.
5. **Configuration decision.** Select among controlled stored-energy, electromechanical and gas mechanisms under the same requirements; charge BOLLEY's cooperative interface. Record the ADR and P92/P113 dispositions. Do not adopt 29, 89 or 120 m/s without a mission-derived requirement. S4's fine-grid 4.569852 m/s first release is a tested campaign result, not a new product minimum or optimum.
6. **One release cell.** Use decisive early coupons to resolve friction/contact/actuator uncertainty; produce coupled dynamics, structural/tolerance, thermal, controls and fault evidence for the selected cell.
7. **Scaling and build package.** Compare 2/4/12-cell campaigns, adjacent payload sizes and independent banks. Produce drawings, BOM, assembly/inspection, instrumentation/calibration, uncertainty and acceptance criteria for a named test article. External review and physical testing remain required.

## Boundaries

This stream owns README presentation assets, new mission studies, requirement/configuration ADRs and selected release-cell interfaces. The closure stream can analyze the existing gas design and supply reusable results. Do not combine evidence from different geometries, payload interfaces or force duties without a new validation path.
