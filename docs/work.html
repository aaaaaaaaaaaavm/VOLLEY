current work

Mission first. Architecture second. Hardware third.

The clean-sheet redesign does not begin by drawing a prettier launcher. It begins by deciding what departure authority is actually worth buying, then finding the smallest machine that supplies it.

01 · now

Close coupled manifest timing

Finish the two-payload terminal-state campaign, publish generated evidence, wire freshness and verification, and synchronize companion snapshots.

02 · next

Run the architecture trade

Independent bays, banks and shared magazine are arrangement choices. Stored-energy, electromechanical and gas systems are mechanism choices. Compare them separately before combining them.

03 · decision

Freeze P92

Select the reference architecture on installed burden, mission benefit, resources, fault exposure, controllability and buildability. Record why the others lost.

04 · release cell

Engineer one real mechanism

Retention, actuator, arrest, load paths, tolerances, sensors, controls, thermal behaviour, faults and interfaces.

05 · scale

2 / 4 / 12 payload arrangements

Start from the 4 kg 3U reference, then test whether the architecture survives adjacent payload classes instead of enlarging CAD.

06 · evidence change

Build the discriminating test article

Manufacturing package, instrumentation, calibration, uncertainty and frozen acceptance criteria before the test.
