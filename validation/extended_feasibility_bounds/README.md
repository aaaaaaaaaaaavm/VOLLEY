# Reproducible lunar and high-speed feasibility bounds

This standalone subset reproduces the captured analytical calculations and figure using only the files in this directory. It contains ideal surrogate cases, not a selected carrier, provider interface, useful lunar lifetime or qualified mechanism.

Verify the captured files and recalculate the numbers without writing outputs:

```bash
python3 check_capture.py
```

The checker uses the Python standard library. Recreate JSON and figures in a separate output directory:

```bash
python3 reproduce_bounds.py --output-dir reproduced
```

Figure generation additionally requires Matplotlib. `python3 reproduce_bounds.py` prints the recalculated JSON without generating files. The archived source files in `inputs/` are read only for their hashes; no SciPy propagation is rerun.

The calculation reproduces the existing ideal transfer/capture and mass boundaries; tangential reference-sphere disposal thresholds; deterministic release margin; translation-only mass-updated recoil; and separation energy/stroke bounds. `NUMERICAL_BOUNDS.json` is the captured reference. `reproduce_bounds.py` contains the extracted arithmetic and plot code; `MANIFEST.json` identifies the supplied files. `MANUSCRIPT_INSERT.md` supplies a concise paragraph and figure caption.

For a 4 kg payload and 300 kg retained host, the 1,000 m/s investigation point requires 1.973684 MJ ideal added relative energy and 2.012598 km constant-force stroke at the 25 g study ceiling. This is a conditional incompatibility with compact, low-acceleration geometry. Acceleration screens are study choices, not payload ratings. Carrier propulsion and individual release velocity remain separate; capture plus subsequent same-perilune circularization to a common 100 km lunar orbit totals 821.239408 m/s in the ideal model.

## Provenance limitation retained

The supplied C0-S1 source and criteria hashes match their original result. The supplied C0-S2 source hash also matches, but its criteria file has SHA-256 `05df6683a6a767b655b9bf83fb09cc65a187f555bf915c73cdd28e908dbd70a9`, while the original result records `332ebca2013f6735f071a295b3c4dba2d74911a31d7e04a55f140de93927a769`. Both identities remain visible. Passing the capture checker confirms reproducibility of the supplied arithmetic and preserved mismatch; it does not repair that provenance gap or certify model completeness.

The 200 m/s reserve is an assumed allowance, not a valid disposal solution. Reference-sphere grazing and zero-energy escape thresholds omit terrain, epoch targeting and finite burns. Navigation covariance, useful lifetime, complete attitude/resource campaign, thermal services, provider facts and independent disposal remain unresolved. No claim of flight performance follows from this subset.

The publication layout is regenerated by `python3 plot_publication.py` from the same captured JSON. The numerical reproducer and original source identities are unchanged.
