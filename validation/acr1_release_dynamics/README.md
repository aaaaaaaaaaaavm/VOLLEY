# ACR1 local release dynamics evidence

Native MuJoCo 3.3.7 contact replay for the unchanged ACR1 reference. Read [the report](../../docs/ACR1_RELEASE_DYNAMICS.md) and [protocol](PROTOCOL.md) before using a number. This local release/arrest sensitivity study does not establish physical repeatability or complete mechanism qualification.

## Evidence

- SOURCE_REPLAY.json and source_nominal.npz/source_adverse.npz: unchanged-function 5 µs force history, source/input identities and exact trace-only instrumentation.
- GEOMETRY_AND_INPUTS.json: 66 CAD-builder-derived rectangular surfaces, exact surrogate inertia and controlling source pins.
- CAMPAIGN.json, runs/*.xml/json/csv and campaign.log: all 42 adopted native runs, native models, histories and diagnostics.
- RESULTS.csv, REFINEMENT.csv, SOLVER_AND_CONTACT_SENSITIVITY.csv and SUMMARY.json: bounded results and numerical comparisons.
- REFINEMENT.png/pdf, DEPARTURE_HISTORIES.png/pdf and NATIVE_POSE_CAPTURE.png: source-linked plots and native-pose collision-proxy capture.
- PHYSICAL_TEST_SPECIFICATION.md: contact identification and release measurements needed to discriminate the remaining models.
- SOFTWARE_ENVIRONMENT.json, requirements-runtime.txt and MANIFEST.json: engine/runtime and file identities.
- history/: superseded pilot collision geometry and native state records, excluded from the adopted matrix. Final geometry adds the complete pallet rectangular members and cap-guide surfaces.

## Verify the captured package

Run `python check_capture.py` with NumPy installed. The checker needs no MuJoCo runtime and does not regenerate the physics. It verifies the exact manifest file set, byte counts, hashes and controlling source identities; recomputes source work/kinetic balance from the dense NPZ histories; checks the native no-contact control from sampled poses/velocities; and recomputes endpoint refinement from individual run records. Native contact-impulse residuals are reaggregated from recorded run diagnostics because complete per-step contact wrenches were not exported. That limitation is explicit in its output.

## Reproduce

Use Python 3.12 with the recorded binary runtime. A separate environment prevents dependence on the transient /tmp path:

```bash
python -m venv /tmp/acr1-release-runtime
/tmp/acr1-release-runtime/bin/pip install --only-binary=:all: -r requirements-runtime.txt
/tmp/acr1-release-runtime/bin/python extract_source.py
/tmp/acr1-release-runtime/bin/python run_campaign.py
python summarize.py
```

The plot step uses NumPy and Matplotlib. Solver runs require no rendering or GPU. All paths resolve relative to this folder and the unchanged sibling validation/acr1 source package. Replaying the force history is not a coupled controller/contact rerun; no physical data are generated by these commands.

Native engine binaries are outside this package. This directory contains project sources and outputs only. The solver is open source; see [MuJoCo](https://github.com/google-deepmind/mujoco) for its license and implementation. No third-party research PDF is redistributed.

The calculation scripts read the sibling ACR1 source package and write this evidence directory. The captured study is computational evidence; provider acceptance and physical test results are separate requirements.
