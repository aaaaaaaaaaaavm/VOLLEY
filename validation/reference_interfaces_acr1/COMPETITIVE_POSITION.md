# Bounded ACR1 competitive position

**25 October 2026.** Companion files are [deployer comparison](DEPLOYER_COMPARISON.csv), [same-input mission results](MISSION_LEVEL_COMPARISON.csv) and [host integration matrix](HOST_INTEGRATION_MATRIX.csv). All use the current ACR1 reference and retain unknowns.

The completed twelve-payload calculation answers a defined resource question. At the same target full states, epoch, generic host, force ceilings and release guards, the tested ACR1 configuration establishes no fuel or initial wet-mass advantage over ideal preplanned spring energies. The latter benchmark is deliberately ideal; it is neither an assertion that a catalog pod offers arbitrary pretrim nor a reason to omit that competitive control.

The frozen reference gives spring devices 72 kg by assumption, versus 156.556720 kg for ACR1. The newly read Nova manual gives three four-slot 12U S4 pods a 39.96 kg bare total, excluding identified installation items. That product evidence strengthens the need for full installed accounting. No native mission result was rerun with that bare mass, and no new propellant saving or penalty is attributed to the product.

For a generic OTV operator, the choice is a complete delivery service: host maneuvers plus conventional separation; an individually commanded mechanism plus host maneuvers; or another mission-permitted method such as payload propulsion or differential drag. ION establishes that customized-slot transport is already offered. Its real installation and mission budgets are unavailable here, so the generic calculation must not be presented as an ION performance prediction.

Recommandability may have value when the target changes after spring energy and integration are frozen. The present studies did not introduce a late target change. No demand, price, revenue, savings or willingness to pay follows. A buyer case needs an actual changed-state requirement, authority to act, a conventional recovery policy and the cost/risk of both responses.

A mounted/free-flying comparison must retain the same delivered states and failure boundary. For equal mechanism and mission, mounted integration is lighter only when its adapter, reinforcement and incremental shared-service burden are below the free-flying bus, power, GNC, communication, thermal and propulsion additions it avoids. Those terms lack a comparable supplier-complete ledger; a numeric break-even map remains open.

Current recommendation: retain ACR1 as the completed computational reference, credit programmable electromagnetic release prior art, and use the documented questions for a future authorized mission/interface exchange. A source-backed adverse result closes its bounded comparison; missing provider/customer inputs remain missing evidence.
