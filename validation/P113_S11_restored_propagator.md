# P113-S11 finite-burn propagator restoration

**Restored 9 October 2026.** The archived [P113-S12 manifest JSON](../analysis/results/manifest_finite_burn.json) named `analysis/finite_burn_departure.py`, but that source file and the S11 run sheet were absent from the repository. Before restoration, S12 could not be reproduced despite containing a source hash. This is an evidence-chain defect, not a numerical failure.

The new [propagator](../analysis/finite_burn_departure.py) is explicitly a **new implementation**, built from the fixed S12 run sheet and its stated 220 s specific impulse, 0.5 deg/s slew-rate limit, 0.05 deg/s² angular acceleration and 30 s settling. It integrates planar two-body gravity with a fixed inertial thrust direction and `m_dot = -T/(Isp·g0)` using SciPy DOP853. The retained mass is set by the exact constant-flow identity after integration. The slew law is the shortest wrapped rest-to-rest triangular/trapezoidal profile under those assumed bounds.

Run `python3 analysis/finite_burn_departure.py`, `python3 -m pytest -q tests/test_finite_burn_departure.py tests/test_manifest_finite_burn.py`, and `python3 analysis/manifest_finite_burn.py --check` with the [pinned environment](../requirements.txt). The full S12 campaign can be regenerated by running that script without `--check`; its JSON stores source hashes and every attempted plan.

**Interpretation:** The result is a bounded **surrogate campaign screen**. The new implementation was constructed after the original numerical outcome was known; matching its six counts is useful regression evidence, not independent confirmation of the optimizer or the mission. No physical thrust, attitude, provider restart, navigation, payload release, collision or installed mass evidence is established. The archive and new result both fail full twelve-payload delivery under all six sampled assumptions; other missions and mechanisms are not ruled out.
