Release-state orbit explorer

Native Orekit 13.1.6, fixed-axis J2. Four prescribed relative release inputs from the same numerical initial position. Move the time control to compare full position and velocity differences at a common epoch.

Projection onto the initial orbital plane; distances in kilometres. The grey circle is a 6378.137 km reference sphere. Projection is not a clearance test. Traces use one-minute samples from the first 95 minutes; markers use the selected epoch; interpolation between displayed positions is not used.

Relative input (m/s)Position difference (km)Velocity difference (m/s)

Differences are from the no-impulse reference at the selected epoch. Velocity differences include orbital direction after phasing; they are not the imparted release delta-v. They are not customer delivery errors or measurement accuracy. No atmosphere, host manoeuvres, hardware uncertainty or conjunction covariance is included. Original CSV: orekit_30s.csv.
