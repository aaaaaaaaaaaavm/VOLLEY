# Superseded geometry records

These are historical source snapshots and exact-capture reports, retained for the engineering correction trail. FM-02 is the current research revision. Earlier nominal passes did not imply actual hardware acceptance.

The source snapshots are not entrypoints from this directory. Reconstruct a historical model in an isolated folder by naming its snapshot mechanism.py and supplying the parent reference/ct_geometry.py and CAD/sweep builders. Source geometry and captured file hashes remain historical; regenerated document metadata need not be byte-identical.
