# Versioned engineering releases

Each release identifies its configuration, repository commit, source, results and distributed artifacts by checksum. Document editions identify the report, presentation and manuscript independently.

Academic source distributions preserve their cited geometry, numerical results and document identities. Later engineering investigations receive separate configuration and release identifiers. Corrections identify the affected version, explain the technical effect and link the checked replacement; earlier source remains traceable.

A repository release records a source distribution. Scientific publication, institutional certification and hardware qualification are separate outcomes. Third-party software and reference material retain their original rights and attribution.
